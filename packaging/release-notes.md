## Install

**VS Code (easiest):** download **mbot2-upload.vsix** below. In VS Code open the Extensions
view (`Ctrl+Shift+X`), click the `···` menu at its top → **Install from VSIX…**, and pick the
file. Nothing else needs installing. Works on Windows, Linux and Apple Silicon Macs.

**Command line only:**

- Windows (PowerShell): `irm https://github.com/Coletronix/mbot2-ble/releases/latest/download/install.ps1 | iex`
- Linux / macOS: `curl -LsSf https://github.com/Coletronix/mbot2-ble/releases/latest/download/install.sh | sh`

Full instructions: https://github.com/Coletronix/mbot2-ble#install
